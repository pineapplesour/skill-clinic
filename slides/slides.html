Pipeline

어떻게: 새 컴퓨터에서 실행, 싼 모델이 분류, 새 컴퓨터에서 재검증

1 SKILL.md → 단계 추출(코드블록)
2 Daytona 새 샌드박스: 업로드 → 순차 실행 → exit code · 로그
3 실패만 Nosana GPU의 Qwen3.5-9B(Ollama)가 분류 stale_package · stale_command · missing_secret · env_specific · network_blocked · bug
4 수정안 → Daytona 또 다른 새 샌드박스에서 재실행 → FIXED / FAIL
5 영수증 리포트 (.md/.json) 판정: HEALTHY · FIXABLE · ENV_SPECIFIC · BROKEN

규칙pass/fail은 exit code가 정한다. 모델은 분류와 수정 제안만.

안전미신뢰 지시라도 전부 샌드박스 안. 끝나면 삭제.

Daytona SDK: create · fs.upload_file · process.exec · delete Nosana: /jobs/list 크레딧 잡 → *.node.k8s.prd.nos.ci
